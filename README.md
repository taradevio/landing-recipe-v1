# Recipe App landing page

A static, mobile-first Astro landing page for a provisional household recipe organizer. The project uses Astro, TypeScript, Tailwind CSS, daisyUI, and Bun 1.3.14 exclusively.

## Commands

```sh
bun install
bun run dev
bun run check
bun test
bun run build
bun run test:e2e
```

`bun run validate:release` intentionally fails while the product name, store link, demo media, and legal/contact links remain provisional. Replace those values in `src/content/siteContent.ts` before release.
